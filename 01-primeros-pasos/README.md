# Primeros pasos

## ¿Qué es Java? Filosofía y usos.
### Origen de Java: de Oak a Java.
Inicialmente, comenzó a desarrollarse en *1991* para tarjetas inteligentes y sintetizadores de TV. El equipo estaba integrado por solo 13 personas al mando de **James Gosling.**

En el año de 1995 Java fue desarrollado por la empresa *Sun MicroSystems* y está basado en **C++**.

El lema de Java es:
> ¡Escríbelo una vez, ejecútalo donde quieras!

Algunas empresas que usan Java son:
* Google.
* Spotify.
* Uber.
* Linkedin.
* Samsung.
* X.
* Netflix.
* Amazon.
* Etc.

#### Independiente de la plataforma
La idea de Gosling era que el lenguaje Java fuera **multiplataforma.** Un lenguaje independiente del sistema operativo con un entorno de ejecución llamado JVM (máquina virtual de Java)

#### El ByteCode
El Bytecode lo crea el compilador de Java (javac). Javac es como un traductor intermedio, toma el código fuente en Java (.java), lo convierte en bytecode y lo deja listo para que la JVM lo ejecute, sin importar el sistema operativo.

#### Características
* Se pueden hacer muchos tipos de aplicaciones (consola, desktop, web, backend, etc.)
* Es multiplataforma.
* Soporta programación orientada a objetos.
* Es un lenguaje fuertemente tipado.
